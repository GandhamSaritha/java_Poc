**Food Ordering System – Java POC**

Overview
A console-based food ordering application developed using Core Java. This POC allows users to select food items, enter quantities, order multiple items, and calculate the final bill.

Features
 - Interactive food menu
 - Multiple food item selection
 - Quantity-based price calculation
 - Multiple item ordering
 - Automatic grand total calculation
 - Bill creation option
